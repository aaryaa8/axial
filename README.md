# Axial — the Primer

A single-page demo of Axial reframed for young-child reading: a tutor that
learns how a child thinks, then teaches her to read.

The centerpiece is an interactive demo. A six-year-old, Maya, reads three words
aloud; the page shows the two-graph mind-model assembling itself (the reading
skills she is learning, and the cognitive strengths underneath), finds the one
upstream bottleneck holding her back, adapts what it teaches, and explains it to
the parent in plain words.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Stack

Vite, React, TypeScript. No backend. The interactive demo is a crafted
illustration, not real student data. Optional voice uses the browser's built-in
speech synthesis, so it needs no keys.

## A note on IP

The real Axial cognitive engine, its taxonomy, and the cited research behind it
are proprietary and are not part of this demo. What is here is presentation and
a scripted illustration of how the product behaves.
